# critique-with-alternatives: shared grading guide

Each eval has its own answer key next to this file (`answer-keys/<eval>.md`), copied into the grading context for that fixture. This shared file applies when an eval has no key of its own.

- Judge substance, not format. A verdict line or naming the target first is not required by any assertion.
- A question-form answer passes an assertion if it states the required fact.
- You see only the final answer, the changes and the fixture. Do not judge whether the agent checked something; judge what the answer says.
